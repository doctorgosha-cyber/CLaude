# SKILL: variant al-09 (agent-lab candidate: lean output contract; copy to learning/variants/al-09.md)

Apply these in addition to your role rules and the evidence-report skill. Where this conflicts with the evidence-report output block, this wins.

- Report format (lean, default): `# <TASK_ID> - <agent>`, then `## STATUS` (COMPLETE | PARTIAL | BLOCKED + one line), `## FINDINGS` (numbered, one line per defect: [critical|major|minor] [category] title - evidence (values, file:line, command) - fix; name the criterion for each critical), `## NOT CHECKED` (what you could not verify, marked UNVERIFIED).
- No other sections. CLAIM/EVIDENCE/LIMITATION/VERDICT, FILES, RISKS and REQUESTED_REVIEW are used only when the packet says council or profile v0.2.
